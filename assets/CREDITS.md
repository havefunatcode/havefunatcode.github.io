# 에셋 크레딧

이 사이트에는 **외부 이미지·오디오 파일은 없습니다.**

- **그래픽**: 모든 픽셀 스프라이트(캐릭터·코인)와 지면·보물상자·배경은
  `js/art/*` · `js/background.js`에서 **코드로 생성/렌더링**합니다. 외부 이미지 파일 없음.
- **사운드**: 점프·코인·낙하·보물 SFX는 `js/audio.js`에서 **Web Audio API로 합성**합니다.
  오디오 파일 없음.
